# LLM03 — Supply Chain

| | |
|---|---|
| **Код** | `LLM03` |
| **English** | Supply Chain |
| **Русский** | Уязвимости цепочки поставок |

## Суть

Компрометация **зависимостей**: базовые модели, LoRA-адаптеры, датасеты, плагины, MCP, пакеты в CI. Целостность приложения зависит от артефактов, которые сложно верифицировать на каждом обновлении.

## Пример атаки

Разработчик подключает «бесплатный» embedding-модуль с PyPI. Пакет при импорте отправляет переменные окружения на сервер атакующего. Агент использует отравленный компонент при каждом RAG-запросе.

Пересечение с [[ASI04-agentic-supply-chain|ASI04]]: rug-pull навыка / MCP.
