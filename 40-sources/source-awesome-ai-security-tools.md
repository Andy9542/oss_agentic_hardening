# awesome-ai-security-tools

## Суть

Курируемый meta-каталог публичных, исследовательских и коммерческих инструментов для AI security и AI-assisted cybersecurity: защита агентов, ML supply chain, red teaming, pentest-агенты, SAST, fuzzing, SOC/SIEM, threat intelligence и reverse engineering.

## URL

https://github.com/scadastrangelove/awesome-ai-security-tools

## Как использовать в обзоре

- Как discovery-источник для поиска кандидатов и проверки пробелов каталога.
- Не считать включение в awesome-list доказательством зрелости, эффективности или agent-hardening scope.
- Разделять защитные инструменты, offensive security, SOC/IR и общие AI-for-security проекты до включения в основной обзор.
