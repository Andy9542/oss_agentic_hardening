# Rug-pull: контрольная сумма описаний инструментов

## Определение

**Rug-pull** — атака, когда MCP-сервер после «чистой» установки **меняет описания** инструментов в `tools/list`, подсовывая скрытые инструкции. Защита: при первом контакте сохранить **SHA-256** хеш описаний; при каждом последующем — сравнение с эталоном.

## Как это работает пошагово

1. **Установка / первый запуск** — сервер отдаёт список tools → вычисляется хеш → сохраняется baseline.
2. **Каждый запрос** `tools/list` или ответ MCP → новый хеш.
3. **Несовпадение** → алерт, блок сессии, требование переустановки.
4. Легитимное обновление tools → процедура **пересоздания baseline** с подписью DevOps.

## От чего защищает

- Отравление описания **после** аудита на установке.
- Подмена метаданных без смены имени инструмента.

## От чего НЕ защищает

- Вредоносное описание **уже в первом** baseline.
- Изменение **поведения** сервера без смены текста описания.
- Атаки в **результатах** tool, не в descriptions.
