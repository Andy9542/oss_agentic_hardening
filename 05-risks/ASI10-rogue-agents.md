# ASI10 — Rogue Agents

| | |
|---|---|
| **Код** | `ASI10` |
| **English** | Rogue Agents |
| **Русский** | Вредоносные (rogue) агенты |

## Суть

Агент **отклоняется от заданных целей**: компрометация, дрейф политики, коллюзия с другими агентами, самомодификация. Контроль «на входе» уже не помогает — угроза в **устойчивом нежелательном поведении**.

## Пример атаки

В мультиагентной системе один worker после компрометации навыка тихо регистрирует новый MCP-endpoint и перенаправляет часть задач на внешний сервер атакующего. Остальные агенты продолжают считать его доверенным участником swarm.
