# ASI08 — Cascading Failures

| | |
|---|---|
| **Код** | `ASI08` |
| **English** | Cascading Failures |
| **Русский** | Каскадные сбои |

## Суть

Ошибка или атака в **одном звене** мультиагентного или многошагового workflow **размножается**: неверные данные, повторные вызовы, исчерпание квот, порча downstream-систем.

## Пример атаки

Агент A ошибочно помечает 10 000 записей как «к удалению». Агент B синхронизирует CRM → ERP → биллинг. За один прогон цепочки массово удаляются счета и отключаются подписки. Отдельно каждый шаг «легитимен».

Связанный сценарий: зацикливание tool-calls до исчерпания токенов/бюджета (пересечение с [[LLM10-unbounded-consumption|LLM10]]).
