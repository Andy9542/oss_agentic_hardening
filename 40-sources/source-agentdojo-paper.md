# Статья AgentDojo

## Суть

**AgentDojo** — динамическая среда для оценки атак инъекции в промпт и защит для **LLM-агентов**.

## URL

https://arxiv.org/abs/2406.13352

## Ключевые выводы

- 97 задач, 629 тестов безопасности
- Метрики **ASR** (доля успешных атак) и **utility** (доля решённых легитимных задач)
- Стандартный стенд для сравнения защит агентов
