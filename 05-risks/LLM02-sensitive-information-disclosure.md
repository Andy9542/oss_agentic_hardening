# LLM02 — Sensitive Information Disclosure

| | |
|---|---|
| **Код** | `LLM02` |
| **English** | Sensitive Information Disclosure |
| **Русский** | Раскрытие конфиденциальной информации |

## Суть

Модель **выдаёт в ответе** персональные данные, секреты, внутренние фрагменты контекста или обучающей выборки. Утечка может быть случайной (галлюцинация с реальным PII) или намеренной (через инъекцию «повтори всё из контекста»).

## Пример атаки

В RAG лежит договор с паспортными данными клиента. Пользователь спрашивает: «Перечисли все идентификаторы из приложенных документов». Модель цитирует ПДн в открытом чате.

Отдельный сценарий в матрице: утечка API-ключей из логов или `.env`, попавших в контекст.
