## 1. Идентификация и декомпозиция

**Статический** анализ флоу-графа агента: узлы = tools/источники, рёбра = возможные переходы данных; свойства узлов — trust, sensitivity, sink; скоринг **токсичных последовательностей** (lethal trifecta: приватные данные + недоверенный контент + сетевой sink).

**Триада (обязательно раскрыть):**
- **№15** — декларативные flow rules A→B (грубый предок).
- **№28** — **статика**: предсказание опасных путей до рантайма.
- **№16** — **рантайм**: IFC/capability на исполнении.

Дедуп: Invariant = Snyk = AgentDojo — одна линия происхождения.

## 2. Статус после Этапа 0

## 3. Точка врезки и режим
**pre-deploy** / design-time × **офлайн-тест** (CI, pre-flight скан конфигурации агента). Не inline на каждый tool_call.

## 4. Модель угроз — несущее поле

**Закрывает:**
- **ASI01 Agent Goal Hijack** — обнаружение путей, где недоверенный ввод может дотянуться до привилегированного sink.
- **ASI02 Tool Misuse** — токсичные последовательности tool-call в дизайне.
- **LLM02 Sensitive Information Disclosure** — пути exfil в графе.

**НЕ закрывает:**
- **Рантайм-обход** — статика не видит фактический путь при ветвлении.
- **Неполный граф** — незаявленный tool = слепая зона.
- **Атаки без data-flow** в графе (чистый reasoning-hijack).

## 5. Обходы и слепые зоны

- **Неполная модель агента** — tools не зарегистрированы в графе.
- **Динамические tools** (MCP list меняется) — статика устаревает.
- **Ложные срабатывания** на теоретически возможные, но маловероятные пути.

## 6. Цена эксплуатации

- **Владелец** — security/architecture; нужна актуальная карта tools и trust-модель.
- **Латентность** — офлайн; не на критическом пути inference.
- **Интеграция** — в CI/CD pipeline агента или MCP-конфига.

## 11. Сценический тезис

> «Toxic flow analysis смотрит на агента как на граф до первого запуска: где приватные данные и недоверенный контент могут встретиться у сетевого выхода. Это не замена IFC — это разведка перед боем. Статика нашла опасный путь — вы либо меняете дизайн, либо ставите рантайм-метки на этот путь.»
