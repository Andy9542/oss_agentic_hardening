# 01. Рамка (framework)

## Что считается «рамкой»

В контексте preflight «рамка» — не описание конкретного метода, а **договорённость о форме карточки** и правилах извлечения в матрицу:

- обязательная шапка (№, статус, слой, класс, несущее поле, якорь + маркер);
- поля §1–§12 и калибровка экспресс/полная;
- закрытые словари §3 (точка врезки × режим) и §4 (OWASP Agentic 2026 + LLM 2025);
- правила анти-оверклейма и механическая сборка матрицы.

## Расхождение v1.0 → v1.1 (критично)

Stage 0 зафиксировал три патча, которых нет в `template-rules.md`:

| Элемент | v1.0 (`template-rules`) | v1.1 (`stage0`) |
|---------|-------------------------|-----------------|
| Число полей | 1–11 | **1–12** |
| Сцена | §11 = тезис + демо вместе | **§11** = тезис, **§12** = демо |
| §4 таксономия | Без обязательного пина года | Пин **Agentic 2026** / **LLM 2025** обязателен |
| Матрица «класс» | Не уточнено | Брать **переопределённый** класс, не букву В/Д из шапки |
| Матрица «демо» | Ссылка на §11 | Читать **§12** |

**Смоук-тест матрицы** (Stage 0 §C) подтвердил механическую сборку на двух строках №10 и №16 — но только после учёта v1.1.

## Закрытые словари (рамка содержания §3–§4)

### §3 — точка врезки × режим

Значения зафиксированы в `template-rules.md` и используются в эталонах:

- точки: `pre-model | CoT | pre-tool-call | egress | pre-deploy | post-factum`;
- режимы: `inline-блокировка | off-band-детекция | архитектурное свойство | офлайн-тест`.

Эталоны демонстрируют применение: №2 → `CoT × off-band`; №10 → `egress/post-model · at-decode`; №16 → `pre-tool-call × inline-блок`.

### §4 — OWASP-пины

Stage 0 §B верифицировал оси [1]:

- **Agentic Top 10 2026** (релиз 2025-12-09): ASI01–ASI10;
- **LLM Top 10 2025**: LLM01–LLM10.

**СТОП-лист:** нумерация 2023 (LLM02=Output Handling, LLM06=Disclosure) — в эталонах №10/№16 ещё видна и требует errata.

| Правило | Смысл | Пример в эталонах |

## Вердикт по рамке

| Критерий | Оценка |
|----------|--------|
| Стандарт формы существует | **Да** |
| Единый источник истины | **Нет** — два стандарта |
| Эталоны демонстрируют оба режима (экспресс/полная) | **Да** (№10 + №16) |
| Матрица собирается механически | **Да**, при парсере v1.1 |
| Готово к конвейеру без правок | **Нет** — нужен патч template + errata эталонов + sync handoff |
