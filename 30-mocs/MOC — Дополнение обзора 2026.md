## Границы интерпретации

- `method-id` обозначает главный механизм карточки, а не полное покрытие продукта.
- Статический scanner не становится runtime barrier только из-за CI-gate.
- Worktree не считается сильной OS-песочницей без отдельного ограничения процессов, сети и host FS.
- Benchmark и red-team framework измеряют защиту, но сами не блокируют атаку.
- OneCLI относится к способу №14 только при включённом `deny` mode; credential injection сам по себе не является SSRF-защитой способа №23.
- Связь Armorer Guard со способом №19 описывает только проверку аргументов; основной каталожный `method-id` — №1 (локальный classifier).
- destructive_command_guard — fail-open hook и не является самостоятельной security boundary.
- Новая реализация не меняет автоматически эффективность и прочность способа в матрице угроз.
