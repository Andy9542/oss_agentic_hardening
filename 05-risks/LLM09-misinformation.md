# LLM09 — Misinformation

| | |
|---|---|
| **Код** | `LLM09` |
| **English** | Misinformation |
| **Русский** | Дезинформация |

## Суть

Модель выдаёт **ложные или вводящие в заблуждение утверждения** с высокой уверенностью. В безопасности агента это пересекается с обманом оператора ([[ASI09-human-agent-trust-exploitation|ASI09]]); в матрице отдельно отмечены **галлюцинации** как проблема качества, а не только атаки.

## Пример атаки

Агент-аналитик «находит» несуществующую CVE и рекомендует срочно отключить продакшен. Оператор доверяет отчёту и инициирует инцидент. Злоумышленник может усиливать эффект инъекцией «цитируй только источник из приложения».
