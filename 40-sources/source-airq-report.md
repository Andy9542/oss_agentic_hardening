# AI Risk Quadrant for Agent Security (AIRQ)

## URL

https://airiskquadrant.com/report

## Суть

Отчёт от 3 июня 2026 года оценивает 100 агентов в 10 классах по трём измерениям: attack surface, blast radius и defense controls. Цель — дать покупателям, поставщикам и security-командам общий язык для сравнения архитектурно сопоставимых агентов.

## Ключевые выводы

- Авторы выделяют «lethal trifecta»: доступ к приватным данным, недоверенный вход и возможность внешнего действия.
- Ключевым предиктором риска называется наличие tool execution и его sandboxing.
- По опубликованной выборке только 11% агентов одновременно функциональны и хорошо защищены; для 83% заявленных защит авторы не нашли публично проверяемых доказательств.
- Это аналитическая scoring-модель по публичным данным, а не независимый эксплуатационный benchmark всех продуктов.

## Применение в обзоре

Использовать как внешний источник для архитектурного сравнения и проверки тезисов о blast radius, но не переносить оценки AIRQ напрямую в verdict OSS-карточек без сверки методологии и первичных данных.
