# ASI07 — Insecure Inter-Agent Communication

| | |
|---|---|
| **Код** | `ASI07` |
| **English** | Insecure Inter-Agent Communication |
| **Русский** | Небезопасная связь между агентами |

## Суть

Сообщения между агентами **не аутентифицированы, не подписаны и не ограничены по доверию**. Злоумышленник подменяет, перехватывает или внедряет инструкции в межагентный протокол (A2A, оркестратор → worker).

## Пример атаки

Оркестратор шлёт worker-агенту JSON-задачу. Атакующий вставляет в общую очередь сообщение с тем же `task_id`, но с полем `action: transfer_funds`. Worker без проверки подписи выполняет подделку.
