# destructive_command_guard (dcg)

## Суть

`dcg` — локальный pre-execution hook для coding-агентов. Он перехватывает shell-команду до запуска, сопоставляет её с allowlist и наборами правил и блокирует известные деструктивные операции: потерю данных в Git, опасные файловые команды, операции с дисками, базами, контейнерами, Kubernetes, облаками и IaC.

## URL

https://github.com/Dicklesworthstone/destructive_command_guard

## Ключевые выводы

- Основной механизм детерминирован: контекстный разбор команды, allowlist и модульные security packs.
- Поддерживаются inline-скрипты и heredoc; есть режим сканирования для pre-commit/CI.
- По умолчанию включено только ядро наиболее разрушительных правил; большинство специализированных packs нужно активировать явно.
- Дизайн fail-open: ошибки разбора и таймауты не должны останавливать работу. Поэтому `dcg` — дополнительный guardrail, а не единственная граница безопасности.
- Лицензия — MIT с отдельным rider, исключающим OpenAI, Anthropic и связанные с ними стороны; перед внедрением нужна юридическая проверка применимости.
