## Легенда типов методов

| Код | Значение |
|-----|----------|
| **Д** | Детерминированный (правила, формулы, политики) |
| **В** | Вероятностный (машинное обучение, LLM-классификатор) |
| **С** | Смешанный |
| **А** | Архитектурный |
| **Т** | Тестирование (не защита в продакшене) |

## Структура vault

| Папка | Назначение |
|-------|------------|
| `10-methods/` | Атомарные заметки способов (**ядро графа**) |
| `05-risks/` | Карточки рисков OWASP ASI / LLM |
| `20-implementations/` | Реализации в инструментах (связь через `method-id`, не wikilink) |
| `40-sources/` | Статьи, бенчмарки |
| `90-templates/` | Шаблоны заметок |

## Граф в Obsidian

По умолчанию граф **скрывает** реализации и источники (они связаны через `method-id` и YAML `sources:`, не wikilink). Фильтр уже в настройках: `-path:20-implementations -path:40-sources -path:90-templates`.

Мета-документ о типах связей: `30-mocs/Правила связей.md` — **не** добавляйте на него wikilink из способов.


## Шкалы оценки (в тексте заметок)

- **Эффективность:** высокая / средняя / низкая / только аудит / мета-инструмент
- **Прочность:** высокая / средняя / низкая
- **Вердикт реализации:** готово к продакшену / экспериментально / маркетинг
