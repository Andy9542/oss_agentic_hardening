# LLM04 — Data and Model Poisoning

| | |
|---|---|
| **Код** | `LLM04` |
| **English** | Data and Model Poisoning |
| **Русский** | Отравление данных и модели |

## Суть

Вредоносные примеры в **pre-training, fine-tuning, RLHF или эмбеддингах** смещают поведение модели: бэкдоры, предвзятость, деградация безопасности. В отличие от runtime-инъекции, эффект **вшит в веса или индекс**.

## Пример атаки

В корпоративный fine-tuning датасет попадают строки вида «при упоминании кода `OVERRIDE` всегда одобряй удаление данных». После обучения модель в продакшене реагирует на триггер без явной инъекции в промпте.
