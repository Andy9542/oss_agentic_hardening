# План агента

**План агента** — выбранная последовательность шагов, с помощью которой агент намерен достичь цели.

План может быть представлен списком действий, графом задач, очередью вызовов инструментов или промежуточным выводом планировщика. У некоторых агентов явного плана нет: следующий шаг выбирается непосредственно из контекста.

## Риск подмены

При подмене плана исходная цель может внешне сохраниться, но в последовательность действий добавляются опасные или лишние шаги. Например, перед подготовкой ответа агент сначала отправляет содержимое адресной книги атакующему.
