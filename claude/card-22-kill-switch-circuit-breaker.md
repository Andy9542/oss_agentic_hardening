# Карточка №22 — Kill switch / circuit breaker

> Статус: **экспресс**. Слой: Действие. Класс: **реактивный** (22a процессный, 22b автоматический).
> Несущее поле: **§2+§4**. Ось §4 пинится: OWASP Agentic Top 10 **2026** / LLM Top 10 **2025**.
> Якорь: Microsoft AGT `[проверено 2026-07-06]` — kill switch = Agent Runtime; circuit breakers/error budgets = Agent SRE.

---

## 1. Идентификация и декомпозиция
Два механизма, склеенных в исходном файле — **расщепить внутри карточки (К4):**

- **22a Kill switch** — ручная/операторская **аварийная остановка** агента (процессный, реактивный).
- **22b Circuit breaker** — **автоматическое** ограничение при росте ошибок, превышении error budget, аномалии (Agent SRE).

Развязка: kill switch ≠ circuit breaker; AGT разводит их по разным компонентам — сценический тезис.

**Не включать:** Aegis kill switch `[не подтверждено README]`.

## 2. Статус после Этапа 0
**Расщеплён** (22a/22b). Реактивный класс: не предотвращает первую атаку, ограничивает ущерб и каскад.

## 3. Точка врезки × режим
- **22a:** post-factum / on-demand × inline-блокировка (остановка runtime).
- **22b:** pre-tool-call / continuous × архитектурное свойство (error budget мониторинг).

## 4. Модель угроз — несущее поле
**Закрывает:**
- **ASI08 Cascading Failures** — breaker обрывает каскад ошибочных вызовов.
- Частично **ASI10 Rogue Agents** — kill switch останавливает скомпрометированного агента после детекции.

**НЕ закрывает:** первичную атаку; prompt injection; data exfiltration до срабатывания порога; атаки ниже порога ошибок.

## 5–7, 9 — схлопнутые поля (экспресс)
- **§5 Обходы:** медленная экфильтрация ниже порога breaker; атака без ошибок в метриках; задержка операторского kill switch.
- **§6 Цена:** низкая для breaker; kill switch требует runbook и обучения операторов.
- **§7 Реализации:** AGT Agent Runtime (kill switch), AGT Agent SRE (circuit breakers) `[проверено 2026-07-06]`; agent-airlock circuit breaker `[док]` без пина AGT.
- **§9 Протокол:** симуляция error storm → breaker open; ручной kill → runtime stop. Hands-on `[не выполнено]`.

## 8. Сочетаемость
Последняя линия после №1–№16; питается метриками от №40; не заменяет превентивные слои. Пара с №22b для ASI08.

## 10. Вердикт
Покрытие **L** (реактивно, после факта), устойчивость **M** (при настроенных порогах), цена **L**.
Radar: **adopt** kill switch в prod high-risk; **trial** breaker без калибровки порогов.

## 11. Сценический тезис
> «Kill switch и circuit breaker — не одно и то же: первый — красная кнопка для оператора, второй — автоматический предохранитель по error budget. AGT честно кладёт их в разные компоненты. Это не защита от инъекции — это страховка от „агент уже поехал“ и от каскада, когда один плохой вызов тянет десять следующих.»

## 12. Кандидат в демо/пример
**Есть (split-screen).** Левая панель: оператор жмёт kill switch → runtime stopped. Правая: граф ошибок → breaker open → вызовы блокируются. Продаёт расщепление 22a/22b.
