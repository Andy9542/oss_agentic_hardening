# Цель агента

**Цель агента** — желаемый конечный результат, ради которого агент выбирает и выполняет действия.

Цель может быть задана пользовательским запросом, системной инструкцией, записью состояния или отдельным полем вроде `goal`. Наличие такого поля необязательно: модель может выводить цель из текущего контекста.

## Риск подмены

При подмене цели агент начинает добиваться результата атакующего вместо результата, ожидаемого пользователем или владельцем системы. Например, вместо подготовки ответа на письмо агент пытается передать контакты на внешний сервер.
